# 战场军需官手机版（Prototype）

一个 mobile-first、无后端、可离线使用的本地单人双阵营桌游辅助原型。玩家在同一台手机上轮流操作 Axis 与 Allies；局面自动保存在浏览器中。

> 本项目当前是 **prototype**，不是完整的规则引擎。卡牌效果、战斗、补给与胜负条件由玩家按实体规则手动判断。

## 已实现

- 新建游戏，以及无需确认页的 Axis / Allies 快速切换
- 六国回合顺序、当前国家和轮数
- 基于 `sources/map.png` 的可缩放、可横向拖动世界地图与可点选区域
- 33 个陆地区域、17 个海域、陆海沿岸关系、地图东西边缘连接和 5 个受控海峡
- 陆军 / 海军 / 空军的国家色棋子；点选地图区域后直接放置或移除，不提供单位移动操作
- 手机横屏战术桌采用单列顺序：地图、单位控制、国家与状态/响应栏、卡牌详情、手牌；双方计分保持在顶部
- 基础版与 Total War 六国完整牌库，共 380 张：德国 68、日本 62、意大利 54、英国 66、苏联 58、美国 72
- 每张牌同时提供原始牌面图片和独立技能说明；手牌可横向浏览并展开查看
- 六国独立牌堆、手牌和弃牌堆；新游戏每国初始 7 张牌，只显示当前阵营的三国手牌
- 牌堆顺序管理：按牌顶顺序抽牌、指定找牌、从牌堆弃牌、置顶、置底和洗牌
- 弃牌堆可指定回到手牌或牌堆顶，也可整堆洗回牌堆
- 状态牌/增强牌与响应牌有独立栏位，可收回手牌或结算后弃置
- 手机端添加带技能说明的自定义卡牌，可直接加入手牌或牌堆顶部
- 顶部战局面板直接调整双方胜利点
- 操作日志和最多 50 步撤销
- `localStorage` 自动保存，刷新或关闭页面后可恢复
- JSON 存档导出和导入
- PWA manifest、离线 service worker 和可安装图标
- GitHub Pages 自动部署工作流

## 本地运行

需要 Node.js 22 或更新的 LTS 版本。

```bash
npm install
npm run dev
```

终端会显示本地地址。手机与电脑处于同一网络时，可使用 Vite 的网络参数：

```bash
npm run dev -- --host
```

核心战术桌针对手机横屏优化，建议游玩时将手机旋转为横屏。常见的 844×390 横屏视口可以在不滚动整个页面的情况下操作地图、地图下方的单位控制台、当前国家手牌与计分；牌堆和弃牌堆使用覆盖式管理面板，面板内部列表可独立滚动。

地图工具栏的“高度”滑杆可在 70–260 像素之间调整地图区域大小；旁边的 − / 适 / ＋ 控制地图内容宽度。地图高度会保存在当前浏览器中。

首次联网打开时，PWA 会在后台下载地图、图标和全部 380 张卡牌图片（约 18 MB）并保存到离线缓存。等待浏览器完成安装后再离线使用，即可查看未曾手动打开过的牌面；以后新增图片会在构建时自动加入离线资源清单。

## 测试与构建

```bash
npm test
npm run build
npm run preview
```

生产文件位于 `dist/`。项目使用相对资源路径，因此也可将该目录部署到任意静态托管服务的子路径。

## GitHub Pages 部署

仓库包含 `.github/workflows/deploy-pages.yml`。首次使用时：

1. 打开 GitHub 仓库的 **Settings → Pages**。
2. 在 **Build and deployment** 中将 Source 设为 **GitHub Actions**。
3. 推送到 `main`，或在 Actions 页面手动运行 **Deploy to GitHub Pages**。

工作流会依次执行 `npm ci`、测试、构建，再发布 `dist/`。

## 存档与同机游玩

- 自动存档只存在当前浏览器的 `localStorage`，没有服务器同步。
- JSON 导出包含双方全部手牌，请勿向不应查看手牌的人展示文件内容。
- 阵营、国家和回合切换会立即生效，并同步显示所选国家的牌库与手牌；同机玩家应自行避免查看对方手牌。
- 清除站点数据会删除浏览器存档；长期战局建议定期导出 JSON。

## Prototype 数据

`src/prototype-data.ts` 明确标注为前端 prototype 适配数据。地图区域、共享边界、受控海峡和回合阶段根据以下项目文件整理：

- `sources/map.png`
- `sources/ARTG006-QuartermasterGeneralWW2-Rulebook-EN-web.pdf`
- `sources/ARTG010-QuartermasterGeneralWW2-TotalWar-Rulebook-EN-web.pdf`

原始 `sources/` 文件保持只读；前端使用未修改的地图副本 `public/qmg-map.png`。适配层不替代现有 Python domain/rules 模型，后续若仓库提供稳定的浏览器数据接口，可替换该层而无需重写 UI 和本地存档流程。

牌库清单位于 `src/generated-card-catalog.ts`，牌面切图位于 `public/cards/`。牌库按项目内的卡牌图集和存档牌组编号整理，技能说明从中文牌面转写为独立文本，方便手机阅读；遇到排版、符号或转写歧义时以显示的原始牌面为准。

地图框架遵循规则书中的连接原则：共享边界才算相邻，只在一点接触不算相邻；中东与巴尔干、黑海与地中海明确不相邻；地图东西边缘首尾相接。海峡是两片海域间的条件相邻，由标有锚点的陆地区域控制。连接会在地图中显示供玩家判断，但本原型不提供单位移动，也不会自动执行建造、战斗或补给。

## 当前限制

- 没有 AI、联网、账号或跨设备同步。
- 不自动执行卡牌效果，不自动计算战斗、补给或胜负。
- 地图连接数据由规则地图人工适配，尚未经过出版方的官方数字地图数据校验。
- 单位只有放置和移除两种局面编辑操作；由卡牌导致的位置变化请以“原区域移除、目标区域放置”记录。
- 不自动判定建造合法性、每国棋子总量、每国每区域一个棋子的限制、补给、战斗或计分。
- 不自动校验空军许可、航程或空军规则。
- 牌面说明由图像文字转写，已校正已发现的明显问题，但仍可能存在个别 OCR 标点或字形误差；原始牌面图片始终保留供核对。
- 法国和中国不是本轮六个可操作国家，尚未作为独立手牌或棋子阵营加入。
- 没有动画或出版级正式美术。
- service worker 会在首次联网访问并加载资源后提供离线能力。
